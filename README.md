# Masar · Right First Time (Position to Person requests)

**Aonami entry for the Emirates Group challenge on Ignyte.**

Checks each P2P request against the rules as it is filled in, tracks every request with its next owner, predicts returns and delays with the evidence, and turns the event log into costed process fixes.

**Demo video (under 3 minutes):** https://www.loom.com/share/02e70c05bc044d35a12869b7f1ad4dae

**Live prototype:** https://aonami-masar.vercel.app. It is hosted, needs no install, and runs entirely in your browser with no cloud AI. Press **Guided demo** for a walk-through.

## Results on our held-out test set

| Measure | Result |
|---|---|
| Bad submissions caught at entry | 99.5% (1,828 of 1,838), 0 clean flagged |
| Return prediction | 95.7% accurate, AUC 0.98 |
| Delay prediction | 78.7% accurate, AUC 0.85 |
| Top recommendation | 6,293 working days saved a year |

> **Data limitation.** The official data pack and test files were not available, so we curated a synthetic sample in the exact shape the brief describes. We generated it with seed 2310, which was never used while building, held back its answer key, ran the prototype on it, and scored the result. These results show how the approach performs on that sample. They are not results on Emirates data.
> The prototype loads the official files the same way: column names are matched by meaning, and other date formats load unchanged.

## Responsible AI, in one line

Masar recommends and a person decides. Nothing is changed or written back automatically, and every result shows the rule, the data or the evidence behind it.
